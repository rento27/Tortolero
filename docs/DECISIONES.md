## Decisiones ratificadas (cerradas al 2026-08-31)

### Relato

| ID | Decisión |
|---|---|
| REL-01 | **Tesis:** ¿cómo puede una tierra nacida del fuego terminar alimentando la vida? |
| REL-02 | **Frase del relato:** «El fuego no se apagó. Solo cambió de lugar.» (cierre, no publicidad). |
| REL-03 | **Frase de marca:** «Aquí la cocina no se sirve. Se revela.» (web, prensa, dossier). |
| REL-04 | **Estructura:** Prólogo/Umbral (sin plato) + 8 tiempos: **Fuego, Tierra, Maíz, Raíces, Sal, Mar, Brasa, Rescoldo.** Acordado con Nico. |
| REL-05 | **Protagonista:** el territorio de Colima. El fuego es la fuerza recurrente, no el protagonista. |
| REL-06 | **Raíces**, en plural. Siempre. |
| REL-07 | **14 Portadores.** El número es dramaturgia, no aforo. No hay versión de 16 ni de 20. |
| REL-08 | **Guardianes del Fuego** es el nombre único de los meseros (no «Custodios», no «Custodios del Umbral»). |
| REL-09 | **TZÓME:** presencia definida, frontera histórica escrita, referencias visuales fijas. Nunca gigante, nunca sobrenatural; sin plumas, penacho ni vestuario indígena histórico. (Ver también `TZOME_direccion.md` para la decisión abierta de medio: animación vs. IA en vivo.) |
| REL-10 | **El Fragmento** llega a domicilio antes de la cena, el comensal lo trae y lo coloca en el **Muro de los Fragmentos** (mueble de nogal existente); la piedra se queda ahí y el comensal se lleva el **tlalchichi**. |

| REL-12 | **Un solo fuego** se enciende ~5 pm, antes de que llegue nadie, para que el último tiempo se cocine en su rescoldo. |
| REL-13 | **Reglas de dirección fijas:** primero la grieta, después la luz · la luz viaja **dentro** de la piedra · las 14 corrientes no llegan sincronizadas · humo contenido (no caldero de bruja) · **prohibido el olor a azufre** · el GO es manual, no automático · **nunca cuatro viales, tres**. |

### Operación y venta

| ID | Decisión |
|---|---|
| OPE-01 | **Una función por semana.** Segunda noche del mismo fin de semana solo si la primera se llena y hay lista de espera. Descartadas tres noches seguidas. |
| OPE-02 | **La reserva se levanta en la web de UMBRAL**, no por teléfono a La Sal. **La sede no se nombra en ningún punto público.** |

| OPE-04 | **Test de carácter, 4 preguntas** en el formulario. Cualquiera cabe en la reserva de un restaurante normal. El reparto lo hace una persona, no un algoritmo. **Nunca se le dice al comensal qué le tocó ni por qué.** |
| OPE-05 | **Anticipo por transferencia** (no retención de tarjeta). Retención → temporada 02. |
| OPE-06 | **Sin merch** en temporada 01. El barro de Colima se guarda para vajilla o temporada 02. |
